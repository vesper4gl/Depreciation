This repository contains the interactive digital resources designed for my **EDES690 Assessment 1**
**How to Access and View the Files**
To view and interact with these web tools on your computer, please follow these simple steps:

**Step 1: Download the files**

Locate the green "<> Code" button near the top right of the file list on this page.

Click the button and select "Download ZIP" from the dropdown menu.

**Step 2: Extract and Open**

Once the ZIP file is downloaded, locate it on your computer and extract/unzip the folder.

Inside the extracted folder, you will find two files:

--> Lesson 1 Icebreaking activities.html

--> Reducing Balance.html

Double-click on either file. It will automatically open in your default web browser (e.g., Chrome, Safari, Edge).

(Note: These are self-contained HTML files. You do not need any special software or an active internet connection to interact with them once they are downloaded.)
